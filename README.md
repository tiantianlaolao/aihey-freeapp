# 教 AI 做出这些小东西

**38 个不用装任何环境的网页小作品**，每一个都配一篇文档。文档全部免费，作品也免费拿走。

里面分成两批，**两批的性质完全不同，我们分开说**：

- **[说出来的（23 个）](#说出来的--23-个)** —— 真的是在造物台上说几句话做出来的。**附上当时的完整对话原话**，包括磨了二十轮还没弄对的那些
- **[我们手写的（15 个）](#我们手写的--15-个)** —— 官方模板，我们自己写的代码。文档是把做法拆开之后重新整理的一条路

把手写的说成"一句话做出来的"，那是骗人。所以分开。

## 这里面真正值钱的东西

不是"怎么做一个 XX"，网上到处都是。是那些**只有真做过才知道、AI 自己不会主动做对**的地方：

**关于怎么跟它说话**（来自 23 段真实对话）

- 报 bug 别说"不对"，说「**什么时候是对的，什么时候是错的**」——对错的分界线就是线索
- 视觉问题连着三轮没改对，**别再说"不对"了**，换成给它看图 / 只改一个 / 先问它是怎么实现的
- 点击没反应 + 控制台没报错 + 代码看着没问题 → **先怀疑有东西盖住了**，AI 查不出这个
- 想问不想改，句首加一句「**只回答，不要改代码**」
- 需求越大，第一句越要划个小范围：「**先只做第一关**」
- 想不清楚要做什么，就先聊：「你觉得 ___ 适合做点什么？**先别动手**」

**关于技术**（来自 15 个手写作品）

- 3D 场景里**海面铺不够大**，整座岛会看起来"浮在天上"
- 低多边形要有棱面，**光说"每个三角形一个颜色"不够**，得先把几何体转成非索引的
- 窗帘打褶是因为**布比它挂着的空间宽**，顶排不收窄，怎么调重力都调不出褶
- 物理模拟用欧拉法积分会**漏能量**，摆自己慢慢停，像有一个并不存在的摩擦力
- `acos` 之前不夹一下范围，浮点误差会返回 NaN，**机械臂当场僵住且不报错**

## 这批作品的共同约束

全部跑在同一条边界里，这条边界既是限制，也是这些做法值得看的原因：

- **不用构建**——没有 Vite / Webpack，浏览器直接跑
- **不带外部资源**——没有图片、没有模型、没有音频文件。图形靠几何体和 CSS，声音靠 WebAudio 现场合成
- **单页能跑**——打开就是全部

## 作品本身也免费拿走

这个仓库**公开的是做法，不是源码**——但作品本身一个都不藏着。

每篇末尾都有一个链接：打开，点右下角的「🎨 改造这个作品」，那个作品就复制成一份**完全属于你的副本**，免费。想改成什么样，接着跟它说话就行，不用配任何环境，也不用自己写代码。

比 clone 一份代码回本地方便得多——那份代码你还得想办法让它跑起来，而这份打开就能改，改完直接是一个能发给别人的链接。

**从改一个现成的开始，比从白纸开始容易得多**：白纸要你先把想要什么想清楚说清楚，改现成的只需要你说"哪里不满意"。
