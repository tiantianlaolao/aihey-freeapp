## 这三轮的走向也很典型：越来越具体

- 第 1 轮：整体（参考这个、能编辑、能打印）
- 第 2 轮：**局部**（加标题、学年、教室三个表头）
- 第 3 轮：**一个点**（导出不该只是复制文本，要能导出表格）

从大到小，每轮只推进一层。**没有一轮是在返工**，全是在往前走。

## 「要方便使用」这种话，为什么这次没坏事

一般来说这类虚词很危险。但这次它后面跟着一句非常硬的约束：**"输出格式要直接可以打印"**。

打印这个词把一堆东西钉死了：纸张比例、黑白也能看清、不能有花哨背景、按钮不能被打进去。**一个具体的使用场景，抵得过十个形容词。**
